Teach Mode 0.3.0 将录制与技能生成放到当前对话中，采用独立仓库和 MPP ZIP 分发。

- 首次在插件商店手动安装并授权；`/teach` 唤起说明，用户明确开始后才订阅 Computer History 事件。
- 结束录制固定事件快照、哈希和采集边界；另行请求 Skill Creator 后生成技能，试运行仍需新的请求。
- 插件停用、卸载或进程退出时释放采集资源并撤下技能；保留教学数据、证据及输出，重新安装后恢复。
- 复用宿主 Node，Windows 首发；支持旧版 Web → Notepad 教学技能。
- 启动及每六小时检查更新，活动任务延后切换，新权限等待批准，更新失败保留旧版。

发布制品包含来源提交、最低 Host 发布版本和 SHA-256。发布流水线要求已发布 Host 的描述文件、固定制品跨仓测试和真实 Windows 对话、采集、试运行及独立输出核验的证据。
